Cầu nối Dữ liệu Mở (API Hub)

Chào mừng các đối tác công nghệ và nhà phát triển. EduNext cung cấp bộ giao diện lập trình ứng dụng (API) mạnh mẽ để bạn có thể truy xuất dữ liệu học liệu, thống kê giáo dục và tích hợp các giải pháp học thuật vào hệ sinh thái của mình.

Xác thực (Authentication)

Hệ thống sử dụng Bearer Token để xác thực các yêu cầu API. Đối với các dữ liệu công khai (Public Data), bạn không cần cung cấp token.

Authorization: Bearer YOUR_API_KEY

Endpoints Phổ biến

GET /api/platform/highlights
Public Access

Lấy dữ liệu thống kê tổng quát và các học liệu nổi bật trên nền tảng EduNext.

Response Example (JSON)
{
  "success": true,
  "stats": {
    "students": 1504,
    "teachers": 82,
    "materials": 258
  },
  "materials": [
    { "MaTaiLieu": 1, "TenTaiLieu": "Giải tích 12 cơ bản", "TenGiaoVien": "Hệ thống" }
  ]
}
GET /api/resources
Scoped Access

Truy vấn kho học liệu theo khối lớp hoặc môn học. Hỗ trợ lọc theo trạng thái Công khai/Nội bộ.

Parameters
  • class_id: ID của khối lớp (0-9)
  • type: Định dạng file (PDF/VIDEO)
Response Status

200 OK / 401 Unauthorized
